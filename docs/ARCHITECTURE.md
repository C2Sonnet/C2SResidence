# ディレクトリ構造

公開ルートは `public/` です。サーバーのドキュメントルートをリポジトリ直下に設定しないでください。

| ディレクトリ | 用途 |
|---|---|
| `public/` | 公開サイト。HTML/CSS/JSと公開可能なデータのみ |
| `app/` | サーバー側の共通機能用（未実装） |
| `database/` | DB定義やマイグレーション用（現在は空） |
| `data/` | 公開可能なプロジェクト状態だけ |
| `materials/` | 公開許可済み材質用（現在は空） |
| `media/` | 公開許可済みメディア用（現在は空） |
| `nginx/` | 公開可能なサーバー設定サンプル |
| `scripts/` | 開発・検証用スクリプト |
| `tools/` | 開発補助ツール用（現在は空） |
| `tests/` | リポジトリ自体の検証 |
| `config.example/` | 運用設定の説明のみ |
| `config/` | ローカル運用設定。Git管理しない |

住宅内部の寸法データや原本は配布物に含めません。正式なモデルが完成した工程から公開用の実装を追加します。
